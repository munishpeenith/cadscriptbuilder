5. One important distinction
Not every CAD problem should be solved with LISP. I'd ask the script writer to distinguish between three types of automation:
Type
	
Best use


AutoLISP
	
Repetitive object edits, text updates, layer changes, geometry checks and simple QA.


Civil 3D .NET API / Dynamo
	
More advanced Civil 3D object manipulation, pipe networks, alignment-dependent geometry and data-aware workflows.


Batch or external automation
	
Processing many DWGs, managing raster files, validating ACC folder structures or coordinating drawing and spreadsheet data.
For example, a LISP can help identify a boundary affected by a shifted alignment, but automatically rebuilding a complicated boundary containing multiple offsets and visibility splays needs more robust geometric logic.
My recommendation: start with LINETYPEFIX and ANNOFIX, because you've already encountered these problems repeatedly. Then build VPQA and CADQA. That gives you immediate practical value before investing in more complex Civil 3D automation.
